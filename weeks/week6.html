WEEK 6 · SUPERVISED LEARNING

Classification in Practice

Classification predicts discrete labels. Model evaluation must account for class frequencies, error costs and whether the task is binary or multiclass.

SECTION 01

Classification outputs

  • A classifier may output a class label, a score or class probabilities. A threshold converts probabilities/scores into a decision for binary classification.
  • Binary classification has two classes; multiclass classification has more than two. Multilabel problems can assign multiple labels to one example.
SECTION 02

Algorithms

  • Logistic regression models class probabilities through a logistic function; multiclass variants can use one-vs-rest or multinomial formulations.
  • A perceptron learns a linear decision boundary. Naive Bayes uses class-conditional likelihoods. KNN uses nearby examples.
  • SVC seeks a margin-maximizing boundary and can use kernels. Decision trees create rule-like partitions; random forests and boosting combine trees.
  • An MLP classifier uses layers and nonlinear activations to learn nonlinear decision boundaries.
SECTION 03

MNIST-style image classification

  • Represent each image as pixel features or use an image-specific representation. Normalize consistently and keep labels separate from input features.
  • Compare simple baselines with more flexible models. Inspect a confusion matrix and examples of common mistakes rather than relying on accuracy alone.
SECTION 04

Confusion matrix

  • True positive (TP): positive case predicted positive. False positive (FP): negative case predicted positive.
  • True negative (TN): negative case predicted negative. False negative (FN): positive case predicted negative.
  • Precision = TP/(TP+FP). Recall = TP/(TP+FN). F1 is the harmonic mean of precision and recall.

\(F_1=2\cdot\frac{\text{Precision}\cdot\text{Recall}}{\text{Precision}+\text{Recall}}\)
SECTION 05

Multiclass and imbalance

  • Macro averaging computes each class's metric then averages classes equally. Weighted averaging weights by class support. Micro averaging aggregates contributions across classes.
  • Stratification can preserve class proportions across splits. Choose thresholds and class weights based on the task's error costs, not only a generic accuracy target.
SECTION 06

Practice

  • Compute precision, recall and F1 from a confusion matrix.
  • Explain when recall is more important than precision.
  • Describe the difference between a multiclass and multilabel problem.
