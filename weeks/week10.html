Overview/Week 10
WEEK 10 · RECOMMENDATION

Recommender Systems

Recommender systems rank or suggest items to users using item properties, interaction patterns, or both.

SECTION 01

Recommendation data

  • A user-item matrix records ratings or interactions. It is commonly sparse because each user interacts with only a small fraction of items.
  • Explicit feedback includes star ratings; implicit feedback includes clicks, views, purchases or watch time.
  • Explore user activity, item popularity, rating distributions and sparsity before choosing an approach.
SECTION 02

Content-based filtering

  • Represent items using attributes such as genre, description or metadata.
  • Create a user profile from features of items the user liked, then rank items by similarity to that profile.
  • It can recommend new items with known features but may over-specialize and depends on useful item metadata.
SECTION 03

Collaborative filtering

  • User-user filtering recommends items liked by users with similar interaction histories.
  • Item-item filtering recommends items similar to those a user previously interacted with.
  • Similarity can be computed using measures such as cosine similarity, but sparse overlaps and popularity effects require care.
SECTION 04

Matrix factorization

  • Approximate the user-item interaction matrix using lower-dimensional user and item latent-factor matrices.
  • A predicted score can be represented as a dot product of a user vector and an item vector, often with bias terms.
  • Regularization helps limit overfitting. Latent factors can capture patterns but are not automatically interpretable.
SECTION 05

Evaluation and limitations

  • Split interactions in a way that reflects the real recommendation setting; temporal splits are often useful when predicting future behaviour.
  • Ranking metrics such as Precision@K, Recall@K or NDCG@K can be more relevant than rating error when the system displays a ranked list.
  • Cold-start users/items, popularity bias, feedback loops and privacy are important limitations.
SECTION 06

Practice

  • Compare content-based and collaborative filtering.
  • Explain why a random split can be unrealistic for future recommendations.
  • Define a ranking metric for a top-10 recommendation list.
