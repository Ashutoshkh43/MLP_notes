WEEK 4 · MODEL CONCEPTS

Model Families & Regression Foundations

This page connects common model families to the kind of relationship they can learn and the assumptions or trade-offs to watch.

SECTION 01

Linear regression

  • A linear model predicts ŷ = w₀ + w₁x₁ + … + wₚxₚ. Coefficients describe the model's fitted change in prediction per unit change in a feature, holding other features fixed.
  • Fit coefficients by minimizing a loss such as sum of squared residuals. Correlated features can make coefficient estimates unstable.
SECTION 02

Polynomial features

  • Polynomial regression adds powers and interactions of input variables, then fits a linear model in the expanded feature space.
  • Increasing polynomial degree increases flexibility and can create overfitting. Scaling can help when polynomial features have very different magnitudes.
SECTION 03

Regularization

  • Ridge adds an L2 penalty on coefficients; Lasso adds an L1 penalty and can drive some coefficients to zero.
  • The regularization strength is a hyperparameter. Larger penalties usually shrink coefficients more strongly; tune using validation or cross-validation.
SECTION 04

Other model families

  • KNN predicts using nearby training observations and is sensitive to scaling and the choice of k.
  • Naive Bayes uses Bayes' rule with a conditional-independence assumption; it is fast and can work well for some high-dimensional data.
  • SVMs seek a separating boundary with a margin; kernels can represent nonlinear boundaries. Scaling is typically important.
  • Decision trees split the feature space into regions and are interpretable at small depth but can overfit.
  • Ensembles combine models. Bagging reduces variance; boosting builds learners sequentially to address prior errors.
SECTION 05

Hyperparameters and tuning

  • Parameters are learned during fit; hyperparameters control model structure or training, such as tree depth, number of neighbours or regularization strength.
  • Grid search tests a defined grid; randomized search samples combinations and can be more efficient in a large search space.
  • Use cross-validation on training data for selection and reserve the final test set for one final assessment.
SECTION 06

Practice

  • Explain underfitting and overfitting using training and validation scores.
  • Compare Ridge and Lasso.
  • Choose two candidate algorithms for a dataset and justify the choice.
