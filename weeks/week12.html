WEEK 12 · NEURAL NETWORKS

Transfer Learning & Pretrained Models

Transfer learning reuses representations learned on a source task to improve learning on a related target task, often when labelled target data is limited.

SECTION 01

Neural-network recap

  • A neural network applies weighted transformations and nonlinear activation functions across layers.
  • Training adjusts parameters to reduce a loss function using an optimizer and gradients.
  • The output layer and loss must match the target task, such as binary classification, multiclass classification or regression.
SECTION 02

Feature extraction

  • Load a pretrained model and use its learned representation as features for a new task.
  • Freeze the pretrained backbone and train a new output head. This is computationally efficient and reduces the number of trainable parameters.
  • Preprocessing must match the model's expected input dimensions and normalization.
SECTION 03

Fine-tuning

  • Unfreeze some or all pretrained layers and continue training on the target dataset.
  • Use a suitably small learning rate to avoid destroying useful pretrained representations too quickly.
  • Compare frozen-feature training with fine-tuning on a validation set; more trainable layers do not guarantee better results.
SECTION 04

Evaluation and pitfalls

  • Keep target test examples out of training and model selection.
  • Watch for source-target domain mismatch, class imbalance, data leakage, overfitting and excessive compute requirements.
  • Record the pretrained model, input transformations, trainable layers, optimizer, learning rate and evaluation protocol.
SECTION 05

Practice

  • Explain feature extraction versus fine-tuning.
  • Describe why fine-tuning often uses a smaller learning rate.
  • Design an evaluation plan for a small labelled image dataset.
