WEEK 3 · RELIABLE WORKFLOWS

Pipelines, ColumnTransformer & Leakage

A pipeline keeps preprocessing and modelling together so the same transformations are applied consistently during training, validation and inference.

SECTION 01

Pipeline

  • `Pipeline` chains transformations and a final estimator. Each intermediate step must support `fit` and `transform`.
  • Pipelines make cross-validation and hyperparameter tuning safer because each fold fits its own transformations.
  • A pipeline also simplifies deployment: pass raw input columns to the fitted pipeline rather than manually repeating every preprocessing step.
SECTION 02

ColumnTransformer

  • Use `ColumnTransformer` to apply different transformations to selected column groups.
  • A typical numeric branch imputes missing values and scales features; a categorical branch imputes and one-hot encodes categories.
  • Keep the target out of the feature transformer unless the task explicitly requires a different setup.
SECTION 03

Example pattern

  • Split data first. Build preprocessing branches, combine them in a `ColumnTransformer`, then create a `Pipeline` with the estimator.
  • Tune parameters using names such as `model__max_depth` or `preprocess__num__imputer__strategy`, depending on the chosen step names.
SECTION 04

Data leakage

  • Leakage occurs when training or model selection uses information unavailable at the moment a real prediction is made.
  • Examples include scaling before splitting, selecting features using the entire dataset, including future values in a time-series feature, and including a target-derived column.
  • A pipeline prevents many preprocessing leaks but cannot fix a flawed split or a feature that encodes the answer.
SECTION 05

Class imbalance

  • Accuracy may look high when one class dominates. Inspect class counts and use precision, recall, F1 and a confusion matrix as appropriate.
  • Consider stratified splitting, class weights or resampling when justified. Resampling must be performed within training folds, not before cross-validation.
SECTION 06

Practice

  • Draw a pipeline with numeric and categorical branches.
  • Identify at least three leakage scenarios.
  • Explain why resampling the entire dataset before splitting can produce optimistic evaluation.
