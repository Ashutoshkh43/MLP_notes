WEEK 7 · MODEL ASSESSMENT

Evaluation, Validation & Scalability

Evaluation estimates how well a model will perform on new examples. Sound evaluation depends on both the metric and the data-splitting strategy.

SECTION 01

Train, validation and test

  • Training data fits model parameters. Validation data supports model and hyperparameter selection. Test data estimates final generalization after decisions are complete.
  • Repeatedly tuning against the test set turns it into a de facto validation set and makes its score optimistic.
SECTION 02

Cross-validation

  • K-fold CV divides training data into k folds, fitting on k−1 folds and evaluating on the remaining fold in turn.
  • Stratified K-fold is useful for classification when preserving class proportions matters. Grouped or time-ordered data may require different splitters.
  • Cross-validation scores vary; report a mean and, when useful, spread across folds.
SECTION 03

Metric selection

  • Regression: MAE, MSE, RMSE and R² each emphasize different aspects of error.
  • Classification: accuracy, precision, recall, F1, ROC-AUC or precision-recall metrics answer different questions. AUC evaluates ranking across thresholds, not one fixed decision threshold.
  • For imbalanced data, inspect per-class metrics and the confusion matrix. State which class is considered positive.
SECTION 04

Thresholds and calibration

  • Changing the probability threshold trades false positives against false negatives.
  • A model's probability ranking and the calibration of its probabilities are distinct properties. If decisions depend on risk estimates, calibration may matter.
SECTION 05

Scalability and reproducibility

  • Large datasets may require efficient algorithms, sparse representations, incremental training or careful feature reduction.
  • Set random seeds where supported, record library versions and keep preprocessing inside the evaluation pipeline.
  • A reproducible result includes the split strategy, metric definition, parameters and enough code/data documentation to repeat the experiment.
SECTION 06

Practice

  • Select a split strategy for independent rows, grouped users and chronological observations.
  • Explain why repeatedly checking test scores creates leakage in model selection.
  • Recommend metrics for a highly imbalanced binary classification problem.
