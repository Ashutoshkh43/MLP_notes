WEEK 5 · SUPERVISED LEARNING

Regression in Practice

Regression predicts a numeric target. The goal is not just to fit a model, but to compare alternatives fairly and understand the errors they make.

SECTION 01

Regression workflow

  • Identify the target and remove target leakage. Split data into train/test sets, using a meaningful split strategy for grouped or time-dependent data.
  • Build a simple baseline, such as predicting the training-target mean. Compare all models on the same held-out rows.
SECTION 02

Algorithms to compare

  • Linear regression provides a transparent baseline.
  • SGD-based regression updates parameters incrementally and can scale to large datasets; feature scaling and learning-rate choices matter.
  • KNN regression averages or weights nearby target values and depends strongly on distance and feature scaling.
  • Decision-tree regression captures nonlinear splits but can overfit when too deep.
  • Random forests average many randomized trees; boosting adds learners sequentially. MLP regression can learn nonlinear mappings but often needs careful scaling and tuning.
SECTION 03

Regression metrics

  • MAE = average(|y − ŷ|). It is easy to interpret in target units and is less sensitive to large errors than squared loss.
  • MSE = average((y − ŷ)²). It penalizes large errors strongly.
  • RMSE = √MSE and returns to the target's units.
  • R² = 1 − SS_res / SS_tot. It compares residual error with a mean-prediction baseline; it can be negative on held-out data.
MetricWhat it emphasizesWatch out for
MAETypical absolute errorDoes not heavily punish a few very large errors
MSE / RMSELarge errors receive more weightCan be dominated by outliers
R²Relative to predicting the target meanCan be negative on test data
SECTION 04

Residual analysis

  • Plot residuals against predictions or important features to detect patterns, changing variance and systematic bias.
  • A low aggregate metric does not guarantee equal performance across all groups. Inspect errors by relevant segments where appropriate.
SECTION 05

Model comparison

  • Use the metric aligned to the real cost of error. Report the split or cross-validation procedure and avoid comparing scores from different test samples as if they were identical.
  • After selecting the model, evaluate once on the untouched test set and document the result.
SECTION 06

Practice

  • Calculate MAE, MSE and RMSE for a small example by hand.
  • Explain why R² can be negative.
  • Compare a linear model with a random forest using both metrics and residual plots.
