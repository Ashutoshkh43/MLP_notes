WEEK 0 · GETTING STARTED

Orientation & the Machine Learning Workflow

Build a mental model of the full machine-learning workflow before writing models. This page is a practical orientation guide; use the active course portal for the exact Week 0 lesson list.

SECTION 01

Learning objectives

  • Distinguish supervised, unsupervised and other common learning settings.
  • Describe the path from a raw dataset to a tested model.
  • Explain features, target, training data, validation data and test data.
SECTION 02

The end-to-end workflow

  • Define the prediction question and what a useful prediction means.
  • Inspect the data: rows, columns, data types, missingness, target distribution and possible leakage.
  • Create a hold-out split before fitting data-dependent transformations.
  • Build a simple baseline before trying sophisticated models.
  • Fit preprocessing and the estimator using training data only.
  • Evaluate with metrics appropriate to the task, inspect errors, and iterate.
  • Document assumptions, random seeds, versions and limitations.
SECTION 03

Problem types

  • Regression predicts a numeric quantity, such as a price.
  • Classification predicts a class or class probability, such as a category.
  • Clustering groups observations without a supplied target.
  • Recommendation estimates which items may interest a user.
  • Time-series work respects time order and often models trend or seasonality.
SECTION 04

Essential vocabulary

  • A feature (X) is an input variable; the target (y) is what the model learns to predict.
  • A parameter is learned from data; a hyperparameter is selected before or around training.
  • Generalization means performing well on data not used to fit the model.
  • Overfitting occurs when a model captures training-specific noise; underfitting occurs when it cannot represent the signal adequately.
SECTION 05

Starter checklist

  • Create a reproducible Python environment and notebook.
  • Load a dataset and inspect shape, columns, data types and target.
  • Record a baseline metric before tuning.
  • Keep a final test set untouched until model selection is complete.
